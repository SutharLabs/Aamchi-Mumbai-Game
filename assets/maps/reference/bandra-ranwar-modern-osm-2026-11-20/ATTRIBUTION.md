# Map data attribution and use

**Map data from OpenStreetMap contributors.**

- Copyright/source information: <https://www.openstreetmap.org/copyright>
- Database license: **Open Database License 1.0 (ODbL 1.0)**, <https://opendatacommons.org/licenses/odbl/1-0/>
- Complete license text: [ODbL-1.0.txt](ODbL-1.0.txt), downloaded from <https://opendatacommons.org/licenses/odbl/odbl-10.txt>.
- Provider: OpenStreetMap contributors; downloaded through the read-only Overpass API at <https://overpass-api.de/api/interpreter>.
- Snapshot, access times, exact query, response details and unchanged raw-file hash: [manifest.json](manifest.json), [source-query.overpassql](source-query.overpassql).

The raw `.osm` file is an actual unmodified query response. The road GeoJSON and OSM-derived layout content retain ODbL attribution/license. The SVG is a preview Produced Work, with attribution embedded and its source data retained here. Original project design commentary does not purport to change the database license.

Commercial use is permitted subject to the license. Keep database notices and license text/link when conveying raw/derived data. Publicly used Derivative Databases are subject to ODbL share-alike; the applicable database/alterations offer must also be considered when publicly using a Produced Work from such a derivative. Do not infer that an exported game or a separate historical-edit layer removes these duties. ODbL does not automatically set the license for unrelated game code/art. Classify and document the actual shipped geographic data and transformation pipeline. See the [ODbL legal code](https://opendatacommons.org/licenses/odbl/1-0/) and [OSMF Produced Work guideline](https://osmfoundation.org/wiki/Licence/Community_Guidelines/Produced_Work_-_Guideline).

For game attribution, use a legible appropriate startup/game/menu/credits location with detailed source/license information accessible. A suitable proposed line is: **Map data from OpenStreetMap contributors — https://www.openstreetmap.org/copyright**. Match the final presentation/data offer to the released use. [OSMF computer-game guidance](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines#Computer_games_and_simulations)

This is a modern geographic reference. Current data is not approval of 1990–1995 road names, one-way/access rules, surfaces, property states or POIs. Nothing here licenses Google Maps/Street View, aerial imagery, parish photographs or heritage-report illustrations.
