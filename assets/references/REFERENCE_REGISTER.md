# Real-world reference register

Project: Aamchi Mumbai Game. Source research checked 19 November 2026; direction updated 20 November. These are source records, not downloaded/shipping assets or cleared production models. The [asset production plan](../../docs/ASSET_PRODUCTION_PLAN.md) owns asset priorities and acceptance gates; the [third-party ledger](../../docs/THIRD_PARTY.md) owns acquisitions/adoptions. Preserve the difference between evidence about a subject and permission to copy an image or mesh.

**Selected scope, updated 22 November 2026:** **present-day Ranwar/Waroda/Chapel Road, Bandra West only**, compressed geography, Windows 10/Android 12 and all four vehicle families player-drivable. The [map report](../../research/BANDRA_REFERENCE_AREA_AND_MAP.md) owns the dated OSM baseline and ~0.2016 km2 first core. Remove the former historical-era hold; current local fidelity, source rights, exact generation and functional/device gates remain. The sole founder has some experience and provisionally ten hours/week.

## Record to complete for each production asset

- Asset ID; real subject/model; category; intended neighborhood, road class, role and reference observation date.
- Coordinates/map anchor and source object ID, with source date and confidence; leave unknown values explicitly pending.
- Each photo's source page, creator, capture date, license/version, attribution, local filename and hash if acquired.
- Geographic-data source/license, extract boundary/date, and transformations, tracked separately from imagery.
- Geometry/model source/license and modifications, tracked separately from both imagery and map data.
- Dimensions with units/source and measured/OEM/map-derived/estimated status; chosen model generation/variant for vehicles; dated primary-source evidence that the exact body/building/garment detail fits the selected present-day.
- Recognizable silhouette/material/proportion features; missing views; artistic compression or simplification.
- Method: original mesh, adapted open asset, reconstruction/scan, or AI-assisted; input rights/terms recorded where applicable.
- Intermediate parked / ambient status and required first-release player-drivable acceptance for every vehicle family; driver/rider, wheel/pivot, collision, handling, mounting/recovery, animation, touch/input and saves on both platforms.
- Review: reference/license packet complete → visual/cultural/architectural review → topology/material review → rig/collision/function tests → engine import and populated-scene performance → adoption. Record reviewer/date, pass/fix/reject and next action at each gate.

No third-party reference image, source-model archive or map extract has been acquired into this folder by this research update. The linked local preflight reports/renders are evidence from the project's own procedural studies; they are not imported catalogue assets or approved production content.
